# TYPO3 Extension `stratis_newsletter`

## Description
This extension adds newsletter templates in project

## Installation and configuring

1) Install via composer `composer require stratis/stratis-newsletter`
2) Add static in root template
3) Change Page Layouts in Page properties to `Page lettre d'information`
4) Do export from Newsletter FE integration. New files will be in `stratis_site/Resources/Private/Partials/Extensions/stratis_newsletter/`
5) Uncomment typoscript code if needed in file `stratis_site/Configuration/TypoScript/Extensions/ext_stratis_newsletter.typoscript`
