Scheduler
=========

Scheduler task allow you to periodically perform an import or an export.

Go to the menu and click on "Scheduler" into "System" section.

On the top bar, click on "Add task".

For more informations about how to configure scheduler task, i invite you to read the official typo3 documentation.

Into the "Class" select box, choose "Import/Export task" into the "e_import_export" section, on the bottom, find the "The ID of the import that should be processed" input and type your Import/Export record ID (you can see it between [] in the record title).
