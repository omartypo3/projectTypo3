Time Field Type¶

It is like value field type but for mysql TIME entries.

You can type de date format into the Details option, for example if you export a str like “12/24/2016”,you will have to type into the Details option : “m/d/Y”, the format is a standard PHP time format.

It is the same for exportation, you can export mysql date entries by using php time format.
